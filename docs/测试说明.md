# 后端测试说明

盘点范围：`backend/tests/**/*.py`（只读，不改测试逻辑）。

约定：

- 单测/集成测试均**不依赖 MySQL / Docker / 网络**（见 `tests/conftest.py`）；Redis、DB 用 Fake/mock。
- `conftest.py` 把 `backend/` 加入 `sys.path`，可直接 `import app.*`。
- 工作目录：`D:\Development\aiproject\AgentInsight\backend`。

## 2. 明显孤立 / 重复

### 同名测试（跨文件或同文件双类）

| 名称 | 位置 | 说明 |
|------|------|------|
| `test_simple_query_skips_validator` | `test_workflow.py` / `test_agent_workflow.py` | 跨文件同名，场景重叠（简单查询跳过 Validator） |
| `test_complex_query_includes_all_steps` | 同上 | 跨文件同名，场景重叠（复杂查询含全部步骤） |
| `test_empty_jobs` | `test_match_algo.py` 内 2 处（`TestTfidfWeights` / `TestSkillMatchScore`） | 同文件方法重名，pytest 可跑但易混淆 |
| `test_keeps_key_fields_only` | `test_context.py` 内 2 处（`TestCompressResume` / `TestCompressJob`） | 同上 |
| `test_get_json_rejects_non_dict_payload` vs `test_get_json_rejects_non_dict` | `test_cache.py` / `test_cache_integration.py` | 近重复：同一防御逻辑两处覆盖 |

### 文件级覆盖重叠（非 bug，冗余偏高）

- **`test_cache.py` ⊂ `test_cache_integration.py`**：cache-aside、LLM 命中/未命中、故障降级、锁均有更完整版本；前者偏冒烟，可考虑合并或明确标注「快速冒烟」。
- **`test_workflow.py` vs `test_agent_workflow.py`**：都做编排端到端；后者接真实 ReportSynthesizer。除上述两个同名用例外，可按「纯编排 / 含真实报告」分工改名以区分。
- **`test_context.py` vs `test_context_integration.py`**：unit 与集成分层合理，但压缩相关方法名大量同构（compress_resume/job/schema/result），检索时需看路径。

### 孤立候选

- **`test_mock_llm.py`**：测的是 `app/core/llm.py` 的 `MockLLMClient`（产品内 mock 客户端，不是测试夹具）。算有效单测，但若该 mock 仅服务离线演示/测试，长期可迁到夹具说明或标注「mock 契约测试」。
- **无真正悬空测试**：各文件均可对应到 `app/` 模块；`test_crawler_run.py` 虽在 unit 下却 import `app.api.crawler`，属 API 层逻辑单测，位置略偏但非孤立。
- 覆盖空档（无对应测试，供后续补）：`app/tools/mineru_client.py`、`app/api/settings.py`、`app/persistence/migrations.py` 等目前无直接测试文件。

## 3. 如何运行

在 `backend` 目录下：

```bash
# 示例：单个文件（任务指定示例）
python -m pytest tests/unit/test_crawler_run.py -q

# 单个文件（integration）
python -m pytest tests/integration/test_api.py -q

# 单个用例
python -m pytest tests/unit/test_state.py::test_happy_path_transitions -q

# 整层
python -m pytest tests/unit -q
python -m pytest tests/integration -q

# 全量
python -m pytest tests -q

# 名称过滤
python -m pytest tests -k "cache" -q
```

说明：

- 无需额外配置文件（无 `pytest.ini`/`pyproject.toml`）；依赖见 `backend/requirements.txt`。
- 默认离线可跑；若本地 venv 在 `backend/.venv`，先激活再执行上述命令。
